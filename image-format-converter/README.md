# Image Format Converter

Convert images between formats locally in your browser. No external services.

## Features

- Upload and preview source image
- Choose target format (PNG, JPEG, WEBP, BMP, GIF, SVG*)
- Convert locally using Canvas APIs
- Preview output and download
- Google Ads placeholder pane at bottom

> Note: Converting raster images to true SVG is not supported.

## Development

```bash
npm install
npm run dev
```

Visit `http://localhost:3002/`.
